# Job Categorization and Notification System

This project scrapes job listings from [Karkidi.com](https://www.karkidi.com), extracts job details, and uses unsupervised machine learning to group jobs based on required skills. A Streamlit app allows users to explore jobs and get notified about relevant ones.

## Features
- Scrapes job title, company, location, experience, skills
- Clusters jobs using Hierarchical Clustering
- Streamlit web app for browsing jobs
